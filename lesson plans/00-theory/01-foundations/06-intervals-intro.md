# Intervals — Introduction

**Track:** theory | **Tier:** intro | **Difficulty:** 2/10
**Prerequisites:** Major Scales — Introduction
**Tags:** intervals, ear-training

## Overview

An **interval** is the distance between two pitches. Naming intervals precisely is the bridge between scales and harmony.

## Size and quality

Count letter names for size (C to E = third). Measure semitones for quality: major, minor, perfect, augmented, diminished.

## Quiz Questions

### Q1. C to E is what size interval?

- A) Third
- B) Second
- C) Fourth
- D) Fifth

**Answer:** A

### Q2. A perfect fifth spans seven semitones from C.

**Answer:** True

### Q3. Minor third has four semitones from C to E♭.

**Answer:** False — three semitones.

### Q4. Octave equals twelve semitones.

**Answer:** True

### Q5. Interval quality includes major and minor.

**Answer:** True

### Q6. C to F is a perfect fourth.

**Answer:** True

### Q7. C to B is a major seventh.

**Answer:** True

### Q8. Intervals are measured between two pitches.

**Answer:** True

### Q9. Letter count and semitone count both matter.

**Answer:** True

### Q10. M3 is wider than m3 by one semitone.

**Answer:** True

### Q11. P8 is also called octave.

**Answer:** True

### Q12. Ear training builds on interval recognition.

**Answer:** True
